# 🌐 Language Translation Tool

A simple web-based language translation tool that allows users to translate text between multiple languages using a translation API.

## 📌 About the Project

The Language Translation Tool is a beginner-friendly web application developed using HTML, CSS, and JavaScript.

Users can enter text, select the source and target languages, and get the translated text instantly.

The application also provides additional features such as copying the translated text, swapping languages, character counting, and text-to-speech.

## ✨ Features

- 🌐 Translate text between multiple languages
- 🔄 Swap source and target languages
- 📋 Copy translated text
- 🔊 Listen to translated text using text-to-speech
- 🔢 Character counter
- ⚠️ Error handling
- 📱 Responsive design
- ⏳ Loading indicator while translating

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Translation API
- Web Speech API

## 🌍 Supported Languages

The application currently supports:

- English
- Hindi
- Kannada
- Malayalam
- French
- Spanish

## ⚙️ How It Works

1. Enter text in the input box.
2. Select the source language.
3. Select the target language.
4. Click the **Translate** button.
5. The application sends the text to the translation API.
6. The translated text is displayed in the output box.
7. The user can copy or listen to the translation.
